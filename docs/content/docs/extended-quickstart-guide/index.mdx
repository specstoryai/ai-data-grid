### Setting Up the Project

**Prerequisites**

* Node.js installed
* A TypeScript project setup (since you're experienced, I'll skip the basic setup steps)

**Installing AI Data Grid**

1. In your project directory, run:

   ```bash
   npm install @specstory/ai-data-grid
   ```

   <Note title="Not on npm yet">
     7.0.0 hasn't been published to npm yet. Until it is, build the packages from source and install the tarballs instead, as described in [Building from source](#building-from-source) below.
   </Note>
2. You may also need to install the peer dependencies if you don't have them already:

   ```shell
   npm i lodash marked react-responsive-carousel
   ```
3. Don't forget to import mandatory CSS

   ```ts
   import "@specstory/ai-data-grid/dist/index.css";
   ```

### Building from source

Until 7.0.0 is on npm, build the packages from a clone of the repository and install the packed tarballs into your app.

**Prerequisites**

* Node.js 24 (the version in the repository's `.nvmrc`; run `nvm use` if you use nvm) and npm
* Git, with access to the [ai-data-grid repository](https://github.com/specstoryai/ai-data-grid)
* An app on React 19 (`react` and `react-dom` `^19.0.0`). React 16, 17 and 18 are not supported.

**1. Clone and build the packages**

```bash
git clone https://github.com/specstoryai/ai-data-grid.git
cd ai-data-grid
npm ci
npm run build
```

`npm ci` installs from the repository's lockfile. `npm run build` builds all three packages into each package's `dist/` folder (including `dist/index.css` for the core and cells packages), then lints them. Two `no-console` lint warnings are expected; errors fail the build.

**2. Pack the tarballs**

```bash
for p in core cells source; do (cd packages/$p && npm pack --pack-destination ../..); done
```

This writes three tarballs to the repository root:

| Tarball | Package |
| --- | --- |
| `specstory-ai-data-grid-7.0.0.tgz` | `@specstory/ai-data-grid`, the grid |
| `specstory-ai-data-grid-cells-7.0.0.tgz` | `@specstory/ai-data-grid-cells`, extra cell renderers |
| `specstory-ai-data-grid-source-7.0.0.tgz` | `@specstory/ai-data-grid-source`, data source hooks |

**3. Install them in your app**

From your app's directory, install the core tarball, plus the others if you use them, in one command. `cells` and `source` depend on `@specstory/ai-data-grid` `7.0.0`, so the core tarball must be in the same command:

```bash
npm i /path/to/ai-data-grid/specstory-ai-data-grid-7.0.0.tgz \
      /path/to/ai-data-grid/specstory-ai-data-grid-cells-7.0.0.tgz \
      /path/to/ai-data-grid/specstory-ai-data-grid-source-7.0.0.tgz
npm i lodash marked react-responsive-carousel
```

npm records them as `file:` dependencies in your `package.json`. Keep the tarballs where they are: `npm ci` and fresh installs of your app read them from that path.

If you install the cells package, npm may warn `ERESOLVE overriding peer dependency` for `@toast-ui/react-editor`, whose article cell editor declares a `react ^17` peer. The install still succeeds and the editor works on React 19. To remove the warning, see the cells package README's [React 19 and the @toast-ui/react-editor peer warning](https://github.com/specstoryai/ai-data-grid/tree/main/packages/cells#react-19-and-the-toast-uireact-editor-peer-warning) section.

Then import the CSS and use the grid as shown below:

```ts
import "@specstory/ai-data-grid/dist/index.css";
import { DataEditor } from "@specstory/ai-data-grid";
```

**Updating to a newer commit**

```bash
cd /path/to/ai-data-grid
git pull
npm ci
npm run build
for p in core cells source; do (cd packages/$p && npm pack --pack-destination ../..); done
```

Then run the `npm i` command from step 3 again in your app. It picks up the rebuilt tarballs even though their version is still `7.0.0`.

### Getting started with data and columns

AI Data Grid is a powerful but flexible library requiring very few concepts required to get started. The grid will need data, columns, and a `getCellContent` callback to convert our data into cells on demand. Because the callback is used, there is no need to pre-format the data in any particular way, so long as it can be transformed into a cell. This example uses a flat array of objects.

```typescript
const data = [
    {
      "name": "Hines Fowler",
      "company": "BUZZNESS",
      "email": "hinesfowler@buzzness.com",
      "phone": "+1 (869) 405-3127"
    },
    ...rest
]
```

The columns of the data grid may contain many options, including icons, menus, theme overrides, however at their most basic they only require a `title` and an `id`. The id is technically optional but it is best not to omit it.

```typescript
const columns: GridColumn[] = [
    {
        title: "Name",
        id: "name"
    },
    {
        title: "Company",
        id: "company"
    },
    {
        title: "Email",
        id: "email"
    },
    {
        title: "Phone",
        id: "phone"
    }
]
```

Each column will automatically size based on its contents. If desired the sise of each column can be overridden by setting the width parameter.

Finally the data grid requires a cell fetch callback. This callback should be memoized using `React.useCallback` or be a static function.

```typescript
const getCellContent = React.useCallback((cell: Item): GridCell => {
    const [col, row] = cell;
    const dataRow = data[row];
    // dumb but simple way to do this
    const indexes: (keyof DummyItem)[] = ["name", "company", "email", "phone"];
    const d = dataRow[indexes[col]]
    return {
        kind: GridCellKind.Text,
        allowOverlay: false,
        displayData: d,
        data: d,
    };
}, []);
```

> 💡 Avoid excessive changes to the identity of the `getCellContent` callback as the grid will re-render from scratch every time it changes.

That is all the basic requirements put together, now the DataEditor can be rendered.

```tsx
return <DataEditor 
        getCellContent={getCellContent} 
        columns={columns} 
        rows={data.length} 
    />;
```
